## 🎯 Estratégias de Venda Implementadas

1. **Headline com Quebra de Culpa (PAS)**: *"Seu filho não gosta de matemática? O problema não é ele."* — Tira a culpa da criança e transfere para a didática tradicional.
2. **Vídeos Demonstrativos na Prática ("Show, Don't Tell")**: Três aulas rápidas de 1 minuto em vídeo (MMC/MDC, Teorema de Tales e Regra de 3) com links diretos apontando para os comentários fixados no YouTube (`&lc=...`).
3. **Mural de Depoimentos Reais**:
   - Destaque para o depoimento da mãe (**Silvana Gomes**).
   - Comentários de alunos que recuperaram nota ou salvaram o ano.
   - Lightbox interativo (ao clicar no print, ele abre ampliado em alta resolução).
4. **Currículo Programático**: 6 módulos visuais deixando claro exatamente o que a criança aprende.
5. **Autoridade do Professor**: Apresentação do Spinisplend com mais de 330 mil seguidores e estudante de Ciência da Computação.
6. **Ancoragem de Preço**: Comparação de uma única hora de aula particular (R$ 80,00) com o valor vitalício do curso (8x de R$ 5,51 ou R$ 37,90 à vista).
7. **Redução de Risco (Garantia de 7 Dias)**: Selo de garantia incondicional colado no botão de checkout da Kiwify.
8. **FAQ Completo**: Quebra das principais objeções dos pais (precisa do jogo instalado, faixa etária, como acessa, vitalício).
9. **Barra Sticky Mobile**: Botão de compra flutuante no celular ao rolar a página.
10. **Meta Tags Open Graph**: Ao enviar o link no WhatsApp ou redes sociais, o card com foto e descrição é exibido automaticamente.

## 🌐 Como Atualizar no GitHub e Ativar o GitHub Pages

### Passo 1: Atualizar os arquivos no repositório

Se você usa o terminal Git:
```bash
# 1. Inicialize ou entre na pasta
git init

# 2. Conecte com o seu repositório do GitHub (substitua pela sua URL)
git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git

# 3. Adicione todos os arquivos
git add .

# 4. Crie o commit
git commit -m "feat: site atualizado com videos demonstrativos, prints reais e FAQ"

# 5. Envie para o GitHub
git branch -M main
git push -u origin main --force
```

*Ou, se preferir pelo navegador: basta acessar o seu repositório no GitHub, clicar em **Add file > Upload files**, arrastar o `index.html` e a pasta `assets/` e confirmar as alterações.*

---

### Passo 2: Ativar o GitHub Pages (Site Online Grátis)

1. No seu repositório no GitHub, clique na aba **Settings** (Configurações).
2. No menu lateral esquerdo, clique em **Pages**.
3. Em **Build and deployment > Source**, selecione **Deploy from a branch**.
4. Em **Branch**, selecione `main` (ou `master`) e a pasta `/(root)`.
5. Clique em **Save**.
6. Em cerca de 1 a 2 minutos, o GitHub vai gerar o link do seu site no ar:
   `https://seu-usuario.github.io/seu-repositorio/`
